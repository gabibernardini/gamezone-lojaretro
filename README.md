# 📌 Sobre o projeto

Este trabalho apresenta uma proposta de landing page promocional para a **GameZone Retro**, uma loja fictícia especializada em jogos e consoles clássicos. O projeto foi desenvolvido com foco na estruturação semântica, navegabilidade e aplicação dos conceitos fundamentais de HTML.

# 🎯 Objetivo do projeto

O objetivo é criar uma página web compacta e funcional, respeitando o limite estrito de **50 linhas de código**, que apresente a loja, seus produtos e tabela de preços de forma clara e organizada.

# 🎨 Elementos apresentados

O projeto contém:
- Título e parágrafos com formatação em **negrito** e *itálico*;
- Imagem temática de jogos retro;
- Lista de consoles clássicos disponíveis;
- Links de navegação interna (âncora para a seção de preços) e externa;
- Tabela de produtos com preços e categorias.

# 🛠️ Ferramentas e Tecnologias utilizadas

O projeto foi desenvolvido utilizando:
- **HTML5:** Estruturação semântica do conteúdo;
- **VS Code:** Editor de código-fonte.
